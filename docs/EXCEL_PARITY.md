## 4. リボン（★人が書いた一覧★・タブ→グループ）

> ★機械で数えていない。抜けが見つかったら足す★

### ファイル
新規／開く／情報／上書き保存／名前を付けて保存／印刷／共有／エクスポート／発行／閉じる／オプション
→ **うち: 読み込む・書き出す のみ**。印刷 **無し**。

### ホーム
| グループ | 主な物 | うち |
|---|---|---|
| クリップボード | 貼り付け（形式を選択）・切り取り・コピー・書式のコピー/貼り付け | 一部（形式を選択・書式のコピー **無し**） |
| フォント | フォント・サイズ・太字/斜体/下線・罫線・塗りつぶし・文字色・ふりがな | 大半 在る（フォント種類・ふりがな **無し**） |
| 配置 | 左中右・上下・折り返し・結合と中央揃え・インデント・方向（縦書き/斜め） | 大半 在る（**上下揃え・方向 無し**） |
| 数値 | 表示形式・通貨・パーセント・桁区切り・小数点増減 | 在る |
| スタイル | **条件付き書式**・テーブルとして書式設定・セルのスタイル | **★全部 無し★** |
| セル | 挿入・削除・書式（行の高さ/列の幅/シートの整理/保護） | 一部（行列の挿入削除は在る・**高さ/幅の数値指定 無し**） |
| 編集 | **オートSUM**・フィル（下/右/連続データ）・クリア・**並べ替えとフィルター**・**検索と選択** | **★全部 無し★** |

### 挿入
ピボットテーブル／テーブル／図・図形・アイコン／**グラフ**／スパークライン／スライサー／
ハイパーリンク／テキストボックス／ヘッダーとフッター／記号と特殊文字
→ **うち: 全部 無し**（読み込んだファイルの中のグラフは**壊さず保つ**が、作れない）

### 描画
ペン／消しゴム／数式に変換
→ **全部 無し**

### ページレイアウト
テーマ／余白・印刷の向き・サイズ・印刷範囲・改ページ／背景／タイトル行／拡大縮小印刷／枠線・見出しの表示印刷
→ **全部 無し**

### 数式
関数ライブラリ（財務/論理/文字列/日付/検索/数学/その他）／**名前の定義**／
参照元・参照先のトレース／**ウォッチウィンドウ**／**計算方法の設定**
→ **うち: 関数の挿入(fx) と 数式の入力は在る。名前の定義・トレース・計算方法 **無し**

### データ
外部データの取得／クエリ／**並べ替え**／**フィルター**／区切り位置／**重複の削除**／
**データの入力規則**／統合／What-If分析／グループ化／小計
→ **★全部 無し★**

### 校閲
スペルチェック／**コメント**／シートの保護／ブックの保護／変更履歴
→ **全部 無し**

### 表示
標準/改ページプレビュー／**ウィンドウ枠の固定**／分割／並べて比較／ズーム／数式バー・枠線・見出しの表示
→ **うち: ズームは在る（Ctrl+ホイール）／数式バーは在る。**ウィンドウ枠の固定 無し**

### ステータスバー
**合計・平均・データの個数・数値の個数・最小値・最大値**（選択範囲の集計）
→ **★全部 無し★**（選んでも何も出ない）
