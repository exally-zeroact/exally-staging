# SPEC — 「きく」共通エンジン 最小設計（対話→チップ→正しい成果物）

経営セッション発。ROADMAP_Exally の **E3**（スイートの署名・堀）。全アプリ共通の部品。実装はExallyセッション。
アマかせ「きく」タブの発想を、スイート共通エンジンへ。

## 0. 完了条件（DoD＝司さんに報告する前に必ず）
テストツール作成 → 全テスト通過（純関数＋jsdom/実UI）→ **Claude Codeが実機で実際に対話・チップ選択・成果物生成してバグ0を確認** → 見せてOK後push。緑≠実機。**捏造禁止**。

## 1. 何か／分かりやすさ（崩さない）
- 白紙のフォームでなく、**「言うだけ → AIが逆に聞く → チップで選ぶ → 正しい成果物が埋まる」**。
- **入口/補助であって唯一の入力ではない**（直接フォームも必ず残す）。
- モバイル前提：**1問1画面・大きなタップチップ・迷わせない**。動いてる絵文字/見た目は自作アイコンに替えない。

## 2. 中核の契約（どのアプリも"きく"を差し込める形）
アプリは **タスク定義** をエンジンに渡す：
- **schema**：埋めたいフィールド（型・必須・許容値）。
- **ground**：チップ候補を**"実データ"から引く供給源**（既存マスタ・過去に使った値・標準選択肢）。★捏造禁止＝候補は実データから。無ければ「その他（自由入力）」で逃がす。
- **context**：そのアプリ/業種のシステムプロンプト。
エンジンは **対話ループ**（1フィールドずつ：逆質問 → チップ提示 → ユーザー選択 → 次 or 完了）→ **schema準拠の構造化オブジェクト**を返す。
アプリは返り値を**検証**して決定論の計算/描画に使う。

## 3. 正しさ・安全（最重要）
- **チップは実データ接地（ground）**＝ハルシネーション禁止。データに無い選択肢を勝手に作らない。
- **きくは"入力補助"のみ**。金額・税・給与の**最終計算は決定論エンジンのまま**。きくが**数値を勝手に確定しない**（最終は必ずユーザー確認）。
- 断定しない・要確認は要確認のまま表示。

## 4. インフラ・コスト
- **サーバ関数 `/api/kiku`**（Claude・**共有 `ANTHROPIC_API_KEY`**・サーバ側・生キーはクライアント非公開）。
- Claudeの**tool/構造化出力**で「次の質問＋チップ候補」or「完了（構造化オブジェクト）」を返す。
- **rate-limit（ask_usage型・回数上限）**＋共通課金で回収。
- ★**キー無し/失敗時＝通常フォームにフォールバック**（きくが無くてもアプリは動く）。dependency方針はExally既存に合わせる。

## 5. 最小版（署名になる最小スコープ＝これだけ先に作る）
- **1つのフロー**で通す（推奨：Exally台帳の「1件入力」または Kyuallyの「当月の変動値入力」）。
- 「言う → 逆に聞かれる → チップで選ぶ → 構造化入力が埋まる」が動く。
- チップ源＝そのアプリの**実マスタ**（従業員名・過去の手当名・標準選択肢）。
- これを**共通部品**にして、他アプリは `schema + ground + context` を渡すだけで使える形にする。

## 6. テスト（2層＋実機）
- **純関数**：schema検証／チップ整形／フォールバック／構造化出力の形。
- **jsdom/実UI**：言う→チップ→埋まる の通し・例外0・キー無しでフォールバック。
- **実機（Claude Code）**：実際に対話→チップ選択→成果物、をバグ0で確認（DoD）。

## 7. 依存・順番
Exally **E0（共有データ＝ground源）→ E1（器）→ E2（台帳）→ E3（きく）**。Kyuallyは E3後に**入力補助**として呼ぶ（計算は決定論のまま）。

## 8. 司さん手番（実支出なし・生キー非タッチ）
`ANTHROPIC_API_KEY`（Exally流用・**新規課金なし**）を Vercel env に設定。実装セッションは生キーを触らない。
