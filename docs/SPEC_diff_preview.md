## 5. この次（レシピ保存）へどう繋がるか

方針 ver.6 の心臓は**レシピ**（＝2回目からAIを呼ばない）。
差分プレビューは**その前段**にあたる。

```
 直す → ★差分プレビュー（今回）★ → 書き込む
                    ↓
              ★この「直しの中身」を名前を付けて残す＝レシピ★
              次の月は 同じレシピを当てるだけ（AIを呼ばない）
```
- **★差分プレビューで見せている物が、そのままレシピの中身になる★**
  だから先に差分プレビューの形を決める（順番は指示役の指定どおり）。
- レシピの設計は**この窓の形が決まってから**出す（先に決めると2回 作り直しになる）。
