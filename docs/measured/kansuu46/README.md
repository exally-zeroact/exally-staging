## ★★実測で 分かった「Excel の くせ」★★（どれも 決めつけずに 数字から 出した）

### ①`COUPDAYS` の basis 1 は「次の 利払日まで」では ない

```
 決済 2008-02-29 ／ 満期 2020-08-31 ／ 年4回
   COUPPCD ＝ 2008-02-29 ／ COUPNCD ＝ 2008-05-31（実 92日）
   ★でも COUPDAYS(basis 1) は 90★
 ⇒ ★前の 利払日 ＋ 3か月（2008-05-29）まで★を 数えている
 ⇒★満期が 月末の 時だけ ずれる★
```

### ②`COUPDAYSNC` は basis 0 だけ 別の 数え方

```
 決済 2008-03-31 ／ 満期 2015-08-31 ／ 年2回
   basis 0 … ★149★＝「1期の 日数 − 前からの 日数」
   basis 4 … ★150★＝素直に 数えた 数
 ⇒★1組だけ 試すと どちらでも 合ってしまう★
```

### ③30/360（basis 0）は ★段の 順番★で 1日 変わる

```
 2008-02-29 → 2008-03-31 は 実Excel で ★31★
   先に「2月末を 30日 扱い」に すると 30 に なって 合わない
   ★先に 31日の 段★ → ★後から 2月末の 段★ なら 31 ⇒ 合う
```

### ④債券の 式が 中で 使う「1期の 日数」は `COUPDAYS` と ★別物★

```
 PRICE(2008-03-31, 2015-08-31, …, basis 1)
   COUPDAYS は ★182★ だが、PRICE の 中は ★184★（前の 利払日 → 次の 利払日 の 実日数）
 ⇒★同じ「1期の 日数」に 2つの 答えが 在る★
```

### ⑤`PRICEMAT` / `YIELDMAT` の「1年の 日数」は ★発行→決済★ で 数える

```
 発2007-11-11 決2008-02-15 満2008-04-13 ⇒ ★365★（発→満 なら 366）
 発2007-01-15 決2008-06-15 満2010-01-15 ⇒ ★365.5★（発→満 なら 365.25）
 ⇒★4組 並べて はじめて 割れた★（1組だけなら どちらでも 合っていた）
```

### ⑥basis 1 の「1年の 日数」は 3段

```
 ①同じ 年 …………… うるう年なら 366
 ②1年 以内で 年を またぐ … 2月29日を 跨いだ 側だけ 366
 ③1年 を 超える …… ★またいだ 暦年の 平均★
    実測 … DISC(2018-07-01 → 2048-01-01) から 逆算した B が
    ★365.2580645161299 ＝ 11323 ÷ 31★
 ⇒★「2月29日が 入っていれば 366」では 全然 合わない★
```

### ⑦`ACCRINT` は ★丸ごと 過ぎた 期間を 1★と 数える

```
 発行 2008-03-05 ／ 初回 2008-09-05 ／ 決済 2008-07-15 ／ 年4回 ／ basis 2
   実Excel ★27.083333…★
   丸ごとの 期間も 実日数(92)/90 で 数えると 27.5 ⇒ ★合わない★
   丸ごと＝1、端だけ 日数で 割ると 1 + 40/90 ⇒ ★合う★
 ⇒★期間が 1つしか 無い 例では 気づけない★
```
