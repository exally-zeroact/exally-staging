## ★正しい 測り方（実ブラウザで 走らせる）★

★幅では なく ★描いた 絵★で 見分ける★。

1. ★実際に 使っている 字（`.rb-item` の `fontFamily`）★を 取る
   （※ 決め打ちしない。画面が 使っている 物を 読む）
2. `await document.fonts.ready` で ★字が 届くのを 待つ★
3. ★絶対に 出ない 字★（`U+10FFFD` など 使われていない 面）を 描いて ★豆腐の 絵★を 作る
4. 印を 1文字ずつ 描いて
   - ★何も 描かれない★（全部 透明）→ 出ていない
   - ★豆腐の 絵と 1点も 違わない★ → 豆腐
   - それ以外 → 出ている
5. ★出る組と 出ない組の 両方で 物差しを 確かめる★
   - 出る組 … `A` `あ` `漢` `＋` `↑` `≡`
   - 出ない組 … `U+10FFFD` `U+10FFFC` `U+E001`
